# 1RC — Crypto Risk Calculator

Bybit 선물 손익비·분할 주문 계산기. 이름은 **1R calc**(거래 한 번의 손실 단위 1R)이자 **1-click risk calc**(LONG/SHORT 한 번에 SL·TP·사이즈). 태그라인 `risk 1. repeat.`

- 아이콘: 손익비 박스(초록 목표 · 노란 진입선 · 빨간 손절) 위의 '1'. 탭 아이콘(`public/favicon.svg`, 32px PNG), 홈 화면 아이콘(`apple-touch-icon.png` 180px, `manifest.webmanifest`의 192·512px)은 모두 같은 그림입니다.
- 링크 미리보기: X·텔레그램 등에 주소를 붙이면 큰 이미지 카드(`public/og.png`, 1200×630)가 뜹니다. 원본은 `scripts/og/og.html`, 다시 만들 때는 `node scripts/og/render.mjs`. 미리보기 태그의 절대 주소는 빌드 때 정해집니다: `SITE_URL` 환경 변수 → `https://1rc.app`.
- 브라우저 저장 키는 이전 이름 그대로(`rrtool.v1.*`)라 이름을 바꿔도 저장된 계산·설정이 그대로 남습니다.

LONG 또는 SHORT를 누르면 그 순간 체결가를 진입가로 잡고, 가격 구조로 SL·TP를 제안해 손익비와 분할 주문표(가격·금액·수량)를 바로 계산하는 개인용 웹 차트입니다. 진입·SL·TP는 차트에서 끌거나 직접 입력해 고칠 수 있고 모든 값은 즉시 다시 계산됩니다. 주문은 넣지 않습니다. 주문표 숫자를 복사해 Bybit에 직접 넣는 용도입니다.

- 시장: **Bybit USDT 무기한 선물** (category=linear, 거래 중인 USDT 무기한 종목만)
- 원칙: SL은 가격 구조(최근 저점·고점 등)로 자동 제안하고, TP는 그 SL에서 손익비로 정합니다(기본 1:1.5, 손익비 점선·입력으로 변경).

## 실행

필요: Node.js 22.12 이상

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 시세는 항상 Bybit USDT 무기한 선물 실시간입니다(데모 데이터 없음).

### Bybit 연결 먼저 확인하기

```bash
npm run check:bybit            # BTCUSDT
npm run check:bybit -- ETHUSDT # 다른 종목
```

종목 정보, 15분봉 200개, 웹소켓 구독·퐁·체결·캔들·티커 수신을 항목별 PASS/FAIL로 보여줍니다. 하나라도 실패하면 종료 코드 1입니다.

## Cloudflare에 배포하기 (npm run dev 없이 쓰기)

주소: https://1rc.app (2026-10-19 Vercel에서 이사, 도메인은 Cloudflare Registrar)

**자동 배포:** GitHub `main`에 올라가면 Cloudflare(Workers Builds)가 받아서 테스트 → 빌드 → 배포까지 합니다 (1~2분). PC에서 할 일은 없습니다. 테스트가 하나라도 실패하면 배포하지 않고 이전 버전이 그대로 떠 있습니다. 진행 상황·실패 기록은 Cloudflare 대시보드 → Workers & Pages → `bybit-rr` → Deployments(배포)에서 봅니다.

- 테스트·빌드는 `wrangler.jsonc`의 `build.command`(`npm test && npm run build`)를 `wrangler deploy`가 먼저 돌리는 방식입니다. 그래서 대시보드의 Build command(빌드 명령)는 **비워 둡니다** (넣어 두면 두 번 돌 뿐 동작은 같음).
- 지금 떠 있는 버전: 1rc.app 페이지 소스의 `<meta name="1rc-build" content="커밋 7자리">`가 GitHub 커밋과 같으면 반영된 것입니다.

처음 한 번만 연결 (Cloudflare 대시보드, 2026-10-19 연결함): Workers & Pages → `bybit-rr` → Settings(설정) → Builds(빌드) → Connect(연결) → GitHub 저장소 `keepgoing2021/Bybit-RR`, 브랜치 `main`. Worker 이름(`bybit-rr`)이 `wrangler.jsonc`의 `name`과 같아야 빌드가 됩니다. Node 버전은 저장소의 `.node-version`(22). 무료 플랜은 빌드 월 3,000분·동시 1개.

**손으로 배포 (예비):** `npx wrangler login`(처음 한 번) → `npm run deploy` (테스트 → 빌드 → 배포)

설정은 `wrangler.jsonc`, 중계 코드는 `worker/index.js`(규칙은 `worker/proxy.js`)입니다. 화면(`dist/`)은 그대로 내보내고 `/bybit-api/*`만 Worker가 Bybit로 넘깁니다 — 열린 중계가 되지 않게 **공개 시세 조회(`GET /v5/market/*`)만** 통과합니다.

**보안 (2026-10-21 점검):**
- 중계(`worker/proxy.js`)는 앱이 부르는 공개 시세 주소 3개(`/v5/market/instruments-info`·`tickers`·`kline`)만, GET만 통과합니다. 손님 머리글(쿠키·API 키)은 넘기지 않아 이 중계로 개인 API(주문·잔고)를 부를 수 없고, 다른 사이트가 방문자 브라우저로 부르면(Sec-Fetch-Site) 거절, 질의 512자 초과는 414, 응답은 늘 JSON + nosniff. 같은 질의는 Cloudflare 가장자리에 잠깐 담습니다(종목 정보 5분, 시세 2초, 오류는 안 담음).
- 화면 응답 머리글은 `public/_headers`: CSP(스크립트는 이 사이트 파일만, 연결은 이 사이트·Bybit REST·웹소켓만, 글꼴은 Google Fonts만, 틀 감싸기 금지), nosniff, X-Frame-Options, Referrer-Policy, Permissions-Policy, HSTS. 그래서 index.html 안에 스크립트를 쓰면 안 됩니다(테마 미리 적용은 `public/theme-init.js`).
- `worker/index.js`는 default 하나만 내보냅니다(이름 있는 내보내기가 있으면 Workers가 시작하지 못함 — 시험이 지킴).
- wrangler는 정확한 버전으로 고정(devDependencies). 무료 플랜에서 중계 요청이 하루 10만 건을 넘으면 그날은 중계만 429가 되고 화면(정적 파일)은 계속 뜹니다.
- 대시보드에서 할 일: 보안 → WAF → 속도 제한 규칙 1개(무료) — 경로가 `/bybit-api/`로 시작, IP당 10초에 30회 넘으면 10초 차단. GitHub·Cloudflare 계정 2단계 인증.

배포 버전은 브라우저가 Bybit REST를 직접 부르고(사용자 IP), 막히면 `/bybit-api` 중계(`worker/index.js`)로 자동 재시도합니다. 실시간 시세(웹소켓)는 항상 브라우저가 직접 연결합니다. 시나리오는 기기·브라우저마다 따로 저장됩니다.

## 사용 흐름

처음 들어오면 **사용 안내**가 한 번 뜹니다. 화면을 어둡게 하고 종목 칸 → LONG/SHORT → 주문 설정 → 차트 → 주문표 순서로 한 곳씩 비추며 설명합니다(건너뛰기·이전·다음, 키보드 ←·→·Enter·Esc). 끝까지 보거나 건너뛰면 이 브라우저에 기억돼 다시 들어와도 뜨지 않고, 상단의 **? 안내** 버튼으로 언제든 다시 봅니다.

1. 상단에서 종목과 차트 시간봉(1분~월봉)을 고릅니다. 종목 칸을 누르면 Bybit 종목 목록처럼 전 종목이 **24시간 거래대금 순**으로 뜹니다(각 줄에 거래대금·현재가·24시간 등락, 시세는 15초마다 새로 받음). 위의 **거래대금 / 상승률 / 하락률** 탭으로 정렬을 바꾸고(고른 탭 표시가 옆 탭으로 미끄러져 옮겨 감, 고른 정렬은 기억), 치면 그 순서 안에서 거르며 코인 이름이 정확히 같은 종목은 맨 위에 둡니다.
2. LONG 또는 SHORT를 누르면 그 순간의 최신 체결가(시장가)를 진입가로 잡아 계산합니다. 다시 누르면 확인 없이 그 순간 가격으로 새로 계산합니다. 연결이 끊겼거나 가격이 오래됐으면 버튼이 잠기고 이유가 표시됩니다.
3. SL: **SL 기준** 시간봉(기본 = 차트 시간봉)에서 엔트리 시점에 이미 확정된 **최근 저점**(LONG, 내려왔다 다시 오른 바닥) / **최근 고점**(SHORT) 중 엔트리 너머에 있는 가장 최근 것. 화면에서는 트레이더 용어 '스윙' 대신 이렇게 부릅니다. 저점 = 양옆 2봉보다 낮은 꼬리(설정 '바닥 크기': 잔물결도 = 1봉, 보통 = 2봉, 큰 굽이만 = 3봉)이고, 오른쪽 봉들이 마감돼야 확정됩니다. 차트에는 그 봉이 노란 띠로 표시됩니다. 상단 **SL 기준**에서 다른 시간봉을 고를 수 있습니다(예: 15분봉 차트에서 1시간봉 최근 저점). 모든 SL 방식에 적용되고, 이미 계산 중이면 같은 엔트리·같은 시각 기준으로 자동 SL을 바로 다시 계산합니다(직접 옮긴 SL은 그대로). 고른 값은 차트를 바꿔도 유지되고, 차트와 같은 시간봉을 고르면 다시 차트를 따라갑니다. 설정의 'SL 방식'에서 'N봉 중 최저·최고가', '직전 봉 저가·고가', '가장 큰 캔들'로 바꿀 수 있습니다. '저점'은 꺾인 바닥, '최저가'는 구간 안에서 가장 낮은 값입니다. 선정 근거(예: 'SL: 15분봉 최근 저점 (21:45 캔들 저가)')는 손절·목표 줄의 '자동' 표시에 마우스를 올리면 보이고, 자동 SL을 못 정했을 때만 그 이유가 손절 줄 아래 노란 칸에 뜹니다(근거 카드는 없앰).
4. TP: 자동 SL에서 기본 손익비 1:1.5 자리(진입 ± 1.5 × 손절폭)에 둡니다. 손익비 점선을 누르거나 손익비 숫자를 고쳐 바로 바꾸고, 기본값은 설정 '새 계산의 TP 손익비'에서 바꿉니다. 자동 SL이 없으면 TP도 비워 둡니다.
5. 박스: 초록은 수익 구간, 빨강은 손실 구간. 노란 띠는 SL을 잡은 캔들입니다(위에 'SL 기준 최근 저점' 같은 이름표). **스탑헌팅존**: 그 캔들의 꼬리 끝(LONG = 저가, SHORT = 고가)에서 바깥쪽 2%~10% 구간을 보라 빗금과 해골 이름표(💀 스탑헌팅존 2~10%)로 칠합니다(이동평균 MA100의 연보라보다 진한 보라). 가로 폭은 손익비 박스와 같고(박스를 옮기거나 넓히면 같이), SL을 차트에서 끌거나 가격칸에 적어 옮기면 구간도 같은 비율로 따라 움직입니다(옮긴 꼬리 = 옮긴 SL ÷ (1 − 스탑 털림 방지 %), 숏은 1 + %). '자동값으로 되돌리기'를 누르면 다시 꼬리 끝 기준입니다. 지금 SL이 그 안에 있으면 이름표가 노랑 '스탑헌팅존 · SL이 안에 있음'으로 바뀝니다. 구간이 화면 밖이면 그 쪽 끝에 '💀 스탑헌팅존 ↓(↑)'만 붙고, 가격축을 끌어 넓게 보면 띠가 보입니다. 해골 이름표는 늘 구간 안(박스 폭 안, 띠가 보이면 띠 안)에만 둡니다. 박스가 좁으면 '💀 헌팅존'으로 줄이고, 목표·손절·손익비 이름표와 겹치면 띠 안에서 옆이나 안쪽으로 옮기며, 그래도 자리가 없으면 해골만 남깁니다. 화면 끝 칩도 자리가 없으면 화면에 보이는 얇은 띠 안에 해골만 그립니다. 오른쪽 가격축의 현재가 아래 숫자는 이번 캔들 마감까지 남은 시간입니다(거래소 시각 기준). SL·TP 선이나 왼쪽 네모 핸들을 끌어 고칩니다. 끄는 동안 차트는 움직이지 않습니다.
6. 박스 오른쪽 점선은 손익비 1:1, 1:1.3, 1:1.5, 1:1.7, 1:2, 1:2.5, 1:3 자리이고, 오른쪽 끝에 빨간 칩(1:x)이 붙어 있습니다(진입 ± 손익비 × 손절폭). 칩이나 점선을 누르면 TP가 그 자리로 갑니다. 마우스를 올리면 칩이 '1:2 → TP'로 바뀌고 안내 문구가 뜹니다. 지금 TP와 같은 자리의 칩은 TP 이름표와 겹쳐서 그리지 않습니다. 손절폭이 좁아 점선이 14px보다 가까우면 겹치지 않게 일부를 생략합니다. 패널의 손익비(빨간 테두리 칸, ✎ 표시)의 숫자를 직접 고쳐도 TP가 그 손익비로 움직입니다(1.5, 1:1.5 모두 입력 가능). 그 아래 **1:1 · 1:1.5 · 1:2 · 1:2.5 · 1:3** 칩을 눌러도 같습니다. 운영자산을 넣으면 칩마다 아래에 **그 자리에서의 수익**(분할이 전부 체결된 뒤 TP에서 청산, 수수료 전, USDT, 1만 이상은 K)이 작게 붙고 '칩 아래 = 분할 전부 체결 후 그 자리 수익' 안내가 뜹니다. 칩의 1:x는 1차 진입가 기준, 칩 아래 금액은 전부 체결 기준입니다. 손익비 카드 머리의 초록 알약은 지금 목표가입니다. 지금 손익비와 같은 칩은 초록으로 켜지고, SL이 진입가 반대편에 없어 TP를 정할 수 없으면 칩이 잠깁니다. SL을 옮기면 TP는 그대로이고 손익비가 다시 계산됩니다.
7. 박스는 진입 봉에서 2봉 오른쪽에서 시작해 최근 캔들을 가리지 않습니다(설정 '박스 시작 위치'에서 변경). 박스 몸통(초록·빨강 영역)을 잡고 좌우로 끌면 박스 위치만 옮겨집니다. 이동량은 봉 수로 저장돼 시간봉을 바꿔도 같은 봉 수만큼 떨어져 있고, 가격은 그대로이며, 진입 봉보다 왼쪽이나 차트 밖으로는 가지 않고, 새로고침해도 유지됩니다.
8. 오른쪽 패널은 카드 네 개(진입 / 손절 / 목표 · 목표가 & 손익비 · 분할 진입 · 리스크)로 묶여 있고, 카드마다 머리에 작은 아이콘과 제목이 있습니다. 글꼴은 Pretendard 하나(사이트에서 직접 내보냄)이고, 가격·금액·손익비 숫자는 같은 글꼴의 고정폭 숫자 + 사선 0이라 자릿수가 세로로 맞고 0과 O가 구분됩니다. 진입·손절·목표는 이름 앞 점(노랑·빨강·초록, 차트 선 색) | % | 오른쪽 정렬 가격칸입니다. **분할 진입** 카드는 줄마다 둥근 판(차수 옆 노란 비중 알약, 가격·금액·수량은 누르면 복사)과 그 아래 '전부 체결 시 예상 평단' 띠, **리스크** 카드는 손절 시(빨강)·목표 시(초록) 두 칸과 총 포지션·필요 레버리지·손익비(전부 체결 시)·손절 시 수수료·수수료 등급입니다(운영자산을 넣어야 보임). 표가 아주 큰 금액(수백만 USDT)으로 카드보다 넓어지면 표만 옆으로 밉니다. 손절은 빨강·목표는 초록 글자입니다. 손절 줄 바로 아래 **스탑 털림 방지**(%, 예전 이름 SL 여유)에서 자동 SL을 꼬리 끝 바깥으로 얼마나 더 둘지 정합니다: 칩 0% · 0.5% · 1% · 2% 또는 직접 입력(0~10%). 바꾸면 지금 계산의 자동 SL이 같은 엔트리·시각 기준으로 바로 다시 잡히고(값은 기억), 직접 옮긴 SL은 그대로 두며 '직접 옮긴 SL은 그대로'라고 알려 줍니다. SL이 스탑헌팅존(꼬리 끝 2~10%) 안에 들어가면 '💀 SL이 헌팅존 안'이 뜹니다. 이 값은 '자동 제안 설정'에서 빠졌습니다. 진입·손절·목표 가격을 직접 입력할 수 있습니다(호가 단위로 맞춤). 진입가를 고치면 '지정가'로 표시되고 손익비·주문표가 그 가격 기준으로 바뀝니다. "자동값으로 되돌리기"는 누를 때의 시장가와 자동 SL·TP로 돌아갑니다(다시 분석하지 않음). "지우기"는 계산을 없앱니다. 지운 직후 5초 동안 아래에 **되돌리기** 알림이 뜹니다(버튼 또는 Ctrl/⌘+Z, 줄어드는 막대가 남은 시간). 작도 하나 지우기·휴지통(이 종목 작도 전부)도 같습니다.
9. 종목이나 데이터 공급원을 바꾸면 계산은 지워집니다. 차트의 박스를 누르면 흰 테두리로 선택되고 Delete(또는 Backspace)를 누르면 지워집니다(입력칸에서 글자를 지울 때는 동작하지 않음, Esc나 바깥 클릭으로 선택 해제).
10. 새로고침해도 마지막 계산과 수정값이 남습니다(브라우저 localStorage).
11. **분할 진입**: 상단 바에 **총 자산**(USDT), 둘째 칸, 분할 수, 비중을 적습니다. 둘째 칸은 이름 옆 스위치로 방식을 고릅니다(Bybit 주문창처럼 같은 칸에서 방식만 바꿈): **[투입금]**(기본) = 이번에 넣을 돈(Bybit 주문 금액, 레버리지 전, 모든 분할 합 — 비우면 총 자산 전부)을 적으면 손절 시 실제 손실을 계산, **[손실 %]** = 손절 시 총 자산의 몇 %를 잃을지 적으면 넣을 돈을 거꾸로 계산. 예: 총 자산 3,000 · 투입금 전부 · 손절폭 3.21% → 손절 시 −96.38 USDT(총 자산 −3.21%), 손실 1%로 바꾸면 투입금 933.66 · 손절 시 −30.00. 리스크 카드의 손절 시·목표 시 아래에는 총 자산 대비 %와 투입금 대비 %가 함께, 차트 이름표에는 '손절 −3.21% · −96.38 USDT'처럼 금액이 같이 나옵니다. 분할 수는 1~10(1 = 한 번에 진입), 비중은 `1:2:3`처럼 적는 칸입니다. 분할별 가격·금액·수량 표(주문표)는 오른쪽 패널에 나오고, 숫자를 누르면 복사됩니다(금액은 쉼표 없이). 복사되면 그 숫자 자리가 1.2초 동안 초록 ✓로 바뀝니다(옆 칸은 가리지 않음). 1차는 엔트리, 2차부터는 엔트리~SL 거리를 분할 수로 나눈 가격이고 차트 박스 안에 점선(2차, 3차…)으로 보입니다. 모든 분할이 체결된 뒤 SL에 맞아도 손실이 정한 %를 넘지 않게 총 포지션을 정하고, 금액은 뒤로 갈수록 크게(1:2:3, 1:2:3:4:5) 나눕니다. '분할별 손실 균등'은 분할마다 SL 손실이 같아지도록 나눕니다(마지막 분할 비중이 더 커짐). 이 두 가지는 비중 이름 옆의 작은 예시 버튼(점점 크게 · 손실 균등)으로 고르거나, 비중 칸에 `1:2:3`·`균등`을 적어도 됩니다. 그 밖에는 `1:1:2`, `20/30/50`, `1, 2, 3`처럼 0보다 큰 숫자를 최대 10칸 적습니다. 칸 수가 곧 분할 수입니다(3칸 → 3분할). 비율을 쓰는 중에 분할 수만 바꾸면 비율을 자르거나 마지막 값으로 채웁니다(20:30:50 → 4분할 20:30:50:50). 잘못 적으면 알려 주고 전 값을 그대로 둡니다. 분할이 촘촘해 박스 안 이름표가 겹치면 선은 모두 그리되 겹치는 이름표만 숨깁니다(전부 체결 평단이 우선). 수량은 Bybit 주문 단위로 내림하고, 최소 주문 금액 미만이면 그 줄을 경고색으로 표시합니다. 주문표의 '체결 시 평단' 칸은 1차부터 그 분할까지 체결됐을 때의 평단입니다(1차 = 진입가, 마지막 = 전부 체결). 아래 요약에 '전부 체결 시 예상 평단'(흰 띠로 강조)·손익비·손익 금액과 필요한 최소 레버리지를 보여줍니다. 손익비와 목표 수익 금액은 바뀔 때 숫자가 살짝 굴러 들어옵니다(SL을 끄는 동안은 멈췄다가 손을 떼면 한 번, 시세만 움직일 때는 없음). **손절 시 수수료**: 전부 체결 후 손절하면 내는 수수료(지정가 진입 + 시장가 손절)와 그것이 손절 손실의 몇 %인지를 얇은 막대로 보여줍니다. 막대 아래 **일반 · VIP1~VIP5** 버튼으로 내 Bybit 등급을 고르면 그 등급 수수료로 다시 계산합니다(고른 등급은 기억, 아래에 지정가·시장가 % 표시). 등급별 값(지정가 / 시장가): 일반 0.02% / 0.055%, VIP1 0.018% / 0.04%, VIP2 0.016% / 0.0375%, VIP3 0.014% / 0.035%, VIP4 0.012% / 0.032%, VIP5 0.01% / 0.032% — Bybit 도움말 파생상품 표(2026-10-12 갱신) 기준이며 지역·이노베이션 존 종목은 다를 수 있습니다. 10% 미만 초록, 20% 미만 노랑, 그 이상 빨강(막대 끝 = 50%). 손절폭이 좁을수록 포지션이 커져 이 몫이 커집니다(이 수수료는 위 손실 금액에 들어 있지 않음). 차트에는 단계별 예상 평단을 다르게 그립니다: 2차·3차… 체결 시는 옅은 잔점선과 테두리 칩, 전부 체결 시는 굵은 흰 점선과 흰 칩(가격축 '예상 평단'). 박스가 좁으면 칩은 '2차 63513.7'처럼 짧게 줄입니다. 패널의 '차트에 평단 선'으로 켜고 끕니다(새로고침해도 유지). SL을 옮기면 분할 가격과 금액이 같이 바뀝니다. 금액은 레버리지 전 포지션 규모이며 수수료·슬리피지·펀딩비는 넣지 않았습니다.
12. 캔들 꼬리는 흰색입니다. 차트 왼쪽 위에 캔들 정보(시·고·저·종, 전 봉 종가 대비 등락·%, 진폭 = (고가 − 저가) ÷ 전 봉 종가)가 나옵니다. 마우스를 캔들 위에 두면 그 캔들, 캔들 오른쪽 빈 곳이나 차트 밖이면 현재 캔들 값이고, 이동평균 값도 같은 캔들 기준으로 바뀝니다.
13. **작도**: 차트 왼쪽 '›'를 누르면 작도 도구가 펼쳐집니다(펼친 상태는 기억). 추세선(2번 클릭), 수평선(1번, 가격축에 가격 표시), 평행 채널(시작점·끝점·폭 3번), 피보나치 되돌림(2번, TradingView처럼 첫 점 1·둘째 점 0, 0.236·0.382·0.5·0.618·0.786). 도구를 고르면 위에 안내가 뜨고 Esc로 취소합니다. 선은 모두 1px입니다. 그린 것을 누르면 선택되어 위에 편집 막대가 뜹니다: 색 견본 8개, 직접 고르기, '기본색'(피보나치는 레벨별 색), 휴지통. 마지막에 고른 색은 다음 작도의 기본색이 됩니다. 선택한 작도는 끝점을 끌어 고치거나 선을 끌어 통째로 옮기고, Delete로 지웁니다. 휴지통은 이 종목 작도를 모두 지웁니다. 작도는 시간·가격에 붙어 확대·스크롤·시간봉 변경을 따라가고, 종목별로 이 브라우저에 저장됩니다.
14. **이동평균선**: 차트에 MA20(파랑)과 MA100(보라)을 그립니다. 종가 단순이동평균이며 진행 중인 봉도 포함해 실시간으로 움직입니다(TradingView MA 기본과 같음). 현재 값은 차트 왼쪽 위에 표시됩니다.
15. **Alt+R**: TradingView처럼 차트 보기를 처음 상태(최근 봉들 + 오른쪽 여백, 가격축 자동 맞춤)로 되돌립니다. 한글 입력 상태에서도 됩니다. 가격축·시간축을 더블클릭해도 그 축만 자동 맞춤으로 돌아갑니다.

자동값이 유효하지 않으면(예: LONG인데 SL 후보가 엔트리 이상) "유효한 자동 SL/TP 없음"과 이유를 표시하고 비워 둡니다. 다른 값으로 몰래 바꾸지 않습니다.

### 15분 순위 (우측 위)

PC·태블릿 화면(폭 641px 이상)에서 상단 바 오른쪽 위에 **15분 순위** 판이 뜹니다. 바 오른쪽에 빈 자리가 있으면 그 자리에 둡니다. 바 높이 안에 들어가면 두 칸형(거래대금 | 상승률, 각 3줄), 바가 한 줄이라 낮으면(넓은 화면) 두 줄형(거래대금 3개 한 줄 + 상승률 3개 한 줄)으로 바꿔 바를 늘리지 않습니다 — 로고 줄은 어느 폭에서도 제자리입니다. 창이 좁아 자리가 없으면 두 줄형으로 바의 마지막 줄 끝에 붙습니다(빈자리가 있으면 그 줄 안에, 없으면 새 줄). 화면 폭이 아니라 실제 자리를 재서 정하므로 윈도우 배율 125~150%에서도 겹치거나 잘리지 않습니다. Bybit USDT 무기한 전 종목의 최근 15분(1분봉 15개: 이번 1분 + 직전 14분) **거래대금 TOP3**와, 그 15분 거래대금 **상위 20종목 중 상승률 TOP3**입니다(거래가 붙은 상승만 — 얇은 종목이 몇 건 체결로 튄 건 빠짐). 값은 (마지막 종가 − 15분 전 시가) ÷ 시가입니다. 줄을 누르면 그 종목 차트로 바뀌고, 지금 보는 종목은 노란 이름으로 표시됩니다. 전 종목 1분봉을 차트와 다른 웹소켓 연결로 받으며(구독 목록이 길면 18,000자씩 나눠 여러 연결), 웹소켓은 이번 1분 봉부터 보내 주므로, 열 때 24시간 거래대금 상위 40종목은 지난 1분봉 16개를 REST로 미리 받아 채웁니다(4개씩 동시에). 나머지 종목은 15분이 차는 동안 상승률 제목 옆에 'n/15분'이 보일 수 있습니다. '+0.00%'로 보일 만큼 작은 오름은 상승률에서 뺍니다. 1초마다 다시 매깁니다. 폰에서는 판을 숨기고 구독도 하지 않습니다.

### 다크 / 라이트

상단 연결 상태 옆 버튼(☀ 라이트 / ☾ 다크, 폰은 아이콘만)으로 바꿉니다. 누르면 새 테마가 버튼 자리에서 원으로 퍼지며 0.5초 만에 화면을 덮습니다(이 효과를 지원하지 않는 브라우저나 '동작 줄이기' 설정에서는 바로 바뀜). 기본은 검정 바탕의 다크입니다. 고른 테마는 이 브라우저에 저장되고, 페이지를 열 때 화면이 그려지기 전에 적용돼 라이트에서도 검정 화면이 번쩍이지 않습니다. 라이트에서는 캔들 꼬리·예상 평단 선·'1:' 같은 흰 강조가 거의 검정으로 바뀝니다.

### 폰에서 쓰기 (화면 폭 640px 이하)

- 위쪽은 두 줄: 종목·차트·SL 기준(차트와 같으면 '차트와 같음'), 그 아래 주문 설정 한 줄 요약(예: `10,000 USDT · 1% · 3분할 1:2:3`). 요약을 누르면 운영자산·손실 %·분할·비중 칸이 펼쳐집니다.
- LONG/SHORT는 화면 아래에 고정된 큰 버튼입니다. 스크롤해도 그 자리에 있습니다.
- 작도 도구는 숨겨 차트를 화면 폭 전체로 씁니다(데스크톱에서 그린 작도는 그대로 보임).
- 입력칸 글자는 16px라 iPhone에서 눌러도 화면이 확대되지 않습니다.
- 사용 안내는 주문 설정 대신 그 요약 버튼을 비추고, 아래 칸을 비출 때는 LONG/SHORT 줄에 가리지 않게 스크롤합니다. '?' 버튼은 아이콘만.

## 선정 이유

### 차트: Lightweight Charts 5.2.1 (TradingView)

- 라이선스 Apache-2.0, 무료. 라이선스의 저작자 표시 요건은 차트 왼쪽 아래 TradingView 로고(기본값)로 충족합니다.
- 시리즈 프리미티브로 박스·라벨·핸들을 직접 그릴 수 있고, 실시간 캔들 갱신을 지원합니다.
- 가격선 드래그는 기본 제공이 아니라 직접 구현했습니다(`src/chart/drag.ts`). 끄는 동안 차트 이동·확대를 끄고, 놓으면 다시 켭니다.
- 데이터 공급은 하지 않으므로 시세 연결은 따로 붙였습니다.

### 시세: Bybit V5 퍼블릭 API

- 무료, API 키 불필요. 사용자가 거래하는 Bybit 선물 종목과 호가 단위(tickSize)를 그대로 씁니다.
- REST: 종목 정보, 캔들(요청당 최대 1000개). 웹소켓: 체결(실시간), 티커(100ms), 캔들(1~60초 간격).
- 엔트리는 캔들 종가가 아니라 체결 스트림의 최신 가격을 씁니다. 캔들 푸시는 최대 수십 초 간격이라 엔트리가 늦어질 수 있기 때문입니다.
- 같은 이유로 차트의 마지막 캔들도 체결이 들어올 때마다 갱신합니다. 캔들 푸시가 오면 Bybit 값으로 다시 맞춥니다. 체결로만 만든 임시 캔들은 '미확정'이라 자동 SL·TP 선정에는 쓰지 않습니다.
- 제약: 웹소켓 연결은 도메인당 5분에 500회 이하.
- REST 경로: `npm run dev`에서는 개발 서버가 `/bybit-api`로 중계합니다(`vite.config.ts`). 배포 빌드는 Bybit를 직접 부르고, 실패하면 `/bybit-api` 중계(`worker/index.js`)로 넘어갑니다. 사용자 PC에서 Bybit가 CORS 헤더에 요청 출처를 돌려주는 것을 확인했습니다.
- 공급원은 `src/data/provider.ts` 인터페이스 뒤에 있어 다른 거래소로 바꿀 수 있습니다.

## 초기 가정 (확정 전략 아님, 화면의 "자동 제안 설정"에서 변경)

"자동 제안 설정"은 접혀 있어도 제목 옆에 지금 적용 중인 값이 한 줄로 보입니다(예: `최근 저점·고점 · 1:1.5`, 바닥 크기가 '보통'이 아니면 `최근 저점·고점 (큰 굽이만) · 1:1.5`). 펼치면 핵심만 나옵니다: **SL 방식**(바로 아래 한 줄 설명), 그 방식의 값 하나(최근 저점 = 바닥 크기 세 단계, N봉 중 최저가 = 봉 수, 가장 큰 캔들 = 찾을 봉 수, 직전 봉 = 없음), **기본 손익비**. 스탑 털림 방지(%)는 패널 손절 줄 아래에 있습니다. 평균 캔들 크기(ATR)·박스·연결 판정은 '고급'에 접혀 있습니다. 값을 바꾸면 지금 계산의 자동 SL·TP도 같은 엔트리·같은 시각 기준으로 바로 다시 계산합니다(직접 고친 값은 그대로).

| 항목 | 기본값 |
|---|---|
| SL 방식 | 최근 저점·고점 (SL 기준 시간봉의 확정 스윙 중 엔트리 너머의 가장 최근 것). 옵션: N봉 중 최저·최고가 / 직전 봉 저가·고가 / 가장 큰 캔들 (모두 SL 기준 시간봉으로 계산) |
| 최근 N봉 방식 | 마감 봉 20개 + 엔트리 시점에 진행 중인 봉(그때까지의 값) |
| SL 기준 시간봉 | 차트 시간봉과 같음. 직전 마감 봉 방식만 한 단계 위: 1·3분→15분, 5분→1시간, 15분·30분·1시간→4시간, 2·4시간→12시간, 6·12시간→1일, 1일→1주, 1주→월봉, 월봉→직전 월봉 (15분→4시간, 4시간→12시간, 1일→1주는 사용자 지정) |
| 급격한 캔들 탐색 범위 | 직전 확정 캔들 50개 (급격한 캔들 방식) |
| 평균 캔들 크기 (ATR) | 캔들 하나가 보통 위아래로 움직이는 폭. 최근 14봉, '최근 봉 중시'(Wilder 방식, TradingView `ta.atr`과 동일). '단순 평균' 선택 가능 |
| 가장 큰 캔들 점수 | 그 캔들의 위아래 길이 ÷ 그 캔들 직전까지의 평소 캔들 크기 (예: 3.21배), 동점이면 최근 캔들, 양봉·음봉 구분 없음 |
| 스탑 털림 방지 (예전 이름 SL 여유) | 0%. 꼬리 끝 가격 기준 % (예: 0.1%면 롱은 저가 × 0.999). 호가 단위는 바깥쪽으로 맞춰 요청한 여유보다 좁아지지 않음. 이전 버전의 틱 단위 값은 0%로 초기화 |
| 저점·고점(스윙) 판별 | 바닥 크기 '보통' = 좌우 각 2봉 (잔물결도 1봉, 큰 굽이만 3봉). 고점은 왼쪽보다 엄격히 높고 오른쪽 이상, 저점은 대칭 |
| 새 계산의 TP | 자동 SL에서 손익비 1:1.5 |
| 분할 진입 | 투입금 방식(비우면 총 자산 전부) · 손실 % 방식은 총 자산의 1%, 3분할(1~10분할), 금액 1:2:3(N분할은 1:2:…:N, 기타는 직접 입력한 비율), 2차부터 엔트리~SL 등간격 |
| 박스 연장 | 최신 봉 + 10봉 |
| 박스 시작 위치 | 진입 봉 + 2봉 |
| 연결 지연 판정 | 15초간 메시지 없음 |
| 가격 유효 시간 | 마지막 체결 60초 이내 |

그 밖의 결정(엔트리 정의, 확정 캔들 판정, 덮어쓰기 방지 방식 등)은 `docs/superpowers/specs/2026-10-18-bybit-rr-tool-design.md`의 결정 사항 표에 이유와 함께 적었습니다.

## 표시 수치

- 위험 거리 = |엔트리 − SL|, 보상 거리 = |TP − 엔트리|, RR = 보상 ÷ 위험 (표기 1:X)
- 현재 R: LONG (현재가 − 엔트리) ÷ 위험 거리, SHORT (엔트리 − 현재가) ÷ 위험 거리
- 손절률·목표 수익률 = 각 거리 ÷ 엔트리. 틱 수도 함께 표시
- 손익비·손익 금액은 가격 기준이며 수수료·슬리피지·펀딩비는 넣지 않았습니다. 수수료는 주문표 요약의 '손절 시 수수료' 한 줄에만 따로 보여줍니다(전부 체결 금액 × 0.075% ÷ 손절 손실).

## 구조

```
src/core/     판단 로직(순수 함수): ATR, 급격한 캔들, 스윙, 자동 선정, RR 계산, 시나리오, 저장, 신선도
src/data/     공급원: Bybit(REST·웹소켓·재연결), 캔들 저장소
src/chart/    박스 좌표·히트 판정·드래그(순수), Lightweight Charts 연결
src/ui/       화면 구성과 상태 연결
tests/unit/   단위 테스트 (Vitest)
tests/e2e/    브라우저 테스트 (Playwright) + 가짜 Bybit 서버
tests/harness/, tests/fixtures/demo/
              테스트 전용 화면과 배속 가짜 시세 (배포 앱에는 들어가지 않음)
```

## 알려진 한계

- 실제 Bybit 연결은 사용자 PC(한국)에서 `npm run check:bybit`로 확인했습니다. 다른 네트워크에서 쓸 때도 이 명령으로 먼저 확인하세요.
- 시나리오는 이 브라우저의 localStorage에만 저장됩니다. 다른 기기와 공유되지 않습니다.
- 활성 시나리오는 하나만 관리합니다. 수수료는 '손절 시 수수료' 한 줄로만 보여주고 손익비·손익 금액에는 넣지 않습니다(고른 Bybit 등급 수수료 기준).
- 월봉은 길이가 달라 지원하지 않습니다.
