개인적으로 사용할 웹 기반 트레이딩 차트 서비스를 만들어줘.

유저가 원하는 순간에 LONG 또는 SHORT를 선택하면, 현재가를 엔트리로 고정하고 과거 캔들과 상위 타임프레임의 가격 구조를 분석해 SL·TP를 자동 제안하는 도구다. 유저는 자동 설정된 SL·TP를 직접 수정할 수 있고, 수정에 따라 손익비(RR)가 실시간으로 달라져야 한다.

첨부 이미지가 있다면 손익비 박스의 시각적 참고 자료로 활용해줘.

1. 핵심 사용 흐름

① 종목과 차트 타임프레임을 선택한다.
② 원하는 순간에 LONG 또는 SHORT 버튼을 누른다.
③ 클릭 순간의 최신 수신 가격을 엔트리로 고정한다.
④ 이전의 가장 급격한 캔들을 찾아 꼬리 끝에 SL을 자동 설정한다.
⑤ 상위 타임프레임의 이전 고점·저점을 찾아 TP를 자동 설정한다.
⑥ 엔트리·SL·TP를 기준으로 RR과 손익비 박스를 표시한다.
⑦ 유저가 SL 또는 TP를 드래그하거나 가격을 입력해 수정한다.
⑧ 변경된 가격에 맞춰 박스·수익률·손실률·RR을 즉시 갱신한다.
⑨ 차트가 진행되는 동안 기준 가격은 유지하고 박스의 오른쪽 끝과 현재 손익 수치를 갱신한다.

핵심 원칙:
목표 RR을 먼저 정해 TP를 역산하지 않는다. 가격 구조로 SL과 TP를 제안하고, RR은 그 결과로 계산한다.

2. 엔트리 설정

- LONG/SHORT 버튼을 누른 순간의 최신 수신 가격을 엔트리로 사용한다.
- 클릭 시각과 해당 가격 데이터의 시각을 구분해서 저장한다.
- 생성 후 엔트리는 고정한다.
- 새로운 가격이 들어와도 엔트리를 따라 움직이지 않는다.
- 데이터가 끊겼거나 오래된 경우 상태를 표시하고, 오래된 가격으로 시나리오를 생성하지 않도록 한다.
- 실제 주문 체결이 아닌 가상 매매 시나리오다.

첫 버전에서는 엔트리 수정을 제외하고 SL·TP 조정에 집중한다.

3. SL 자동 선정

현재 차트 타임프레임에서 엔트리 시점 이전의 확정 캔들을 탐색한다.

- LONG: 선정된 캔들의 저가, 즉 아래꼬리 끝을 SL로 사용한다.
- SHORT: 선정된 캔들의 고가, 즉 위꼬리 끝을 SL로 사용한다.
- 꼬리가 없다면 해당 캔들의 저가 또는 고가를 사용한다.
- 진행 중인 캔들과 엔트리 이후 데이터는 선정에 사용하지 않는다.

‘가장 급격한 캔들’의 정확한 기준은 아직 확정되지 않았다. 우선 다음을 조정 가능한 초기 가정으로 구현해줘.

- 탐색 범위: 직전 확정 캔들 50개
- ATR 기간: 14
- 급격함 점수: 해당 캔들의 전체 고저폭 ÷ 해당 캔들 직전의 ATR
- 점수가 가장 높은 캔들을 선정
- 동점이면 더 최근 캔들을 선정
- 양봉·음봉 여부는 기본적으로 필터링하지 않는다.
- SL 버퍼 기본값은 0이며, 필요하면 틱 단위로 추가할 수 있게 한다.

위 숫자와 측정 방식은 확정된 매매 전략이 아닌 MVP 기본값이다. 설정에서 변경할 수 있게 하고 코드에서도 선정 로직을 분리해줘.

LONG의 SL이 엔트리 이상이거나 SHORT의 SL이 엔트리 이하라면 ‘유효한 자동 SL 없음’을 표시하고 수동 설정을 허용한다. 설명 없이 다른 캔들로 바꾸지 않는다.

4. TP 자동 선정

유저가 선택한 상위 타임프레임의 가격 구조를 사용한다.

- LONG: 가장 최근의 확정 스윙 고점
- SHORT: 가장 최근의 확정 스윙 저점

숏에서 이전 저점을 사용하는 것은 롱의 이전 고점 조건을 대칭 적용한 기본 설계다.

‘이전 고점·저점’은 직전 캔들의 고가·저가가 아니라 스윙 구조를 의미한다.

- 스윙 판별은 좌우 각각 2개의 봉을 확인하는 방식을 MVP 기본값으로 사용한다.
- 판별에 필요한 봉 수는 설정 가능하게 한다.
- 상위 타임프레임은 기본적으로 현재 차트보다 큰 값을 제안하고 유저가 변경할 수 있게 한다.
- 엔트리 시점에 이미 확정된 상위 타임프레임 캔들로 확인할 수 있었던 스윙만 사용한다.
- 이후 데이터로 뒤늦게 확정된 스윙을 과거 시나리오의 TP로 사용하지 않는다.

LONG의 TP가 엔트리 이하이거나 SHORT의 TP가 엔트리 이상이면 ‘유효한 자동 TP 없음’을 표시하고 수동 설정을 허용한다. 임의의 RR에 맞춘 가격으로 대체하지 않는다.

5. SL·TP 수동 수정

자동으로 설정한 SL·TP는 초기 제안값이다.

- 차트에서 SL선과 TP선을 각각 드래그할 수 있어야 한다.
- 설정 패널에서 정확한 가격을 직접 입력할 수도 있어야 한다.
- SL 수정 시 엔트리와 TP는 유지한다.
- TP 수정 시 엔트리와 SL은 유지한다.
- 특정 RR을 유지하기 위해 반대쪽 가격선을 자동 이동시키지 않는다.
- 드래그 중에도 가격·변동률·RR·박스 크기를 즉시 갱신한다.
- 가격은 종목의 최소 호가 단위에 맞춘다.
- 선과 핸들 조작이 차트 이동·확대·축소 동작과 충돌하지 않게 한다.
- 수정한 값은 실시간 가격 업데이트와 새로운 캔들 생성 이후에도 유지한다.

자동 제안값과 현재 적용값은 별도로 저장한다.

- SL과 TP 각각 ‘자동 / 수동 수정’ 상태를 표시한다.
- ‘자동 설정으로 복원’하면 최초 생성 당시의 SL·TP로 돌아간다.
- 복원은 새로운 시장 데이터로 다시 분석하는 동작이 아니다.
- 엔트리는 복원 시에도 유지한다.

6. RR과 손익 계산

- 위험 거리 = |엔트리 − SL|
- 보상 거리 = |TP − 엔트리|
- RR = 보상 거리 ÷ 위험 거리
- 표시 형식 = 리스크:보상 1:X

현재 R 배수:
- LONG: (현재가 − 엔트리) ÷ 위험 거리
- SHORT: (엔트리 − 현재가) ÷ 위험 거리

손절률과 목표 수익률은 각각 위험 거리와 보상 거리를 엔트리로 나눈 백분율로 표시한다. 현재 가격 수익률은 롱·숏 방향을 반영한다.

계산값은 현재 적용된 SL·TP를 기준으로 갱신한다. 수량을 입력하지 않은 상태에서 금액 손익을 임의로 표시하지 않는다. 수수료·슬리피지·레버리지를 반영하지 않은 가격 기준 수치임을 표시한다.

유효 조건:
- LONG: SL < 엔트리 < TP
- SHORT: TP < 엔트리 < SL

조건을 벗어나거나 위험 거리가 0이면 이유를 표시하고, 정상적인 RR 값으로 표시하지 않는다. SL 또는 TP가 없는 경우에도 유저가 수동으로 완성할 수 있어야 한다.

7. 차트와 화면 구성

어두운 배경의 캔들 차트를 중심으로 구성한다.

차트 상단:
- 종목 선택
- 차트 타임프레임 선택
- TP 분석용 상위 타임프레임 선택
- LONG / SHORT 버튼
- 데이터 연결 상태

차트 위:
- 엔트리·SL·TP 수평선과 가격 라벨
- 반투명 초록색 수익 영역
- 반투명 빨간색 손실 영역
- SL·TP 드래그 핸들
- 목표 손익비와 현재 R 배수
- SL 선정에 사용한 캔들 강조
- TP 선정에 사용한 스윙 지점 표시

SHORT에서는 수익 영역이 엔트리 아래, 손실 영역이 위에 표시된다.

설정 패널:
- 급격한 캔들 탐색 범위와 ATR 기간
- SL 버퍼
- 스윙 판별 봉 수
- SL·TP 직접 입력
- 자동 설정으로 복원

선정 근거도 확인할 수 있게 한다.
예: ‘SL: 15분봉 10월 18일 14:15 캔들 저가’
예: ‘TP: 4시간봉의 확정 스윙 고점’

8. 자동 진행과 저장

- 박스 왼쪽 끝은 시나리오 생성 시점에 고정한다.
- 오른쪽 끝은 최신 캔들에서 일정 거리 앞까지 자동 연장한다.
- 새로운 캔들이 생성되어도 기존 엔트리·SL·TP를 재선정하지 않는다.
- 확대·축소·스크롤 시 도형이 정확한 시간·가격 좌표에 붙어 있어야 한다.
- 종목이나 시간봉을 변경해도 다른 종목의 시나리오가 섞이지 않게 한다.
- 새로고침 후에도 시나리오와 수동 수정값을 복원한다.

첫 버전은 활성 시나리오 하나를 관리한다. 활성 시나리오가 있을 때 LONG/SHORT를 다시 누르면 실수로 덮어쓰지 않도록 처리한다. 수동 종료와 삭제를 제공한다.

9. 구현 및 결과물

실제 사용 가능한 MVP를 구현해줘.

먼저 커스텀 도형·가격선 드래그·실시간 캔들 갱신을 지원하는 차트 라이브러리와 시장 데이터 공급원을 선정한다. 라이선스, 지원 종목, 비용, 데이터 지연과 제약을 확인하고 선택 이유를 짧게 설명한다.

시장과 데이터 공급원이 지정되지 않았다면 연결이 쉬운 공개 시장 데이터로 초기 구현하고, 선택한 시장을 명시한다. 데이터 연결부는 다른 공급원으로 교체할 수 있게 분리한다.

데모 데이터와 실제 시장 데이터는 명확히 구분한다.

다음을 검증한다.
- LONG/SHORT별 SL·TP·RR 계산
- 클릭 순간 엔트리 고정
- 엔트리 이후 데이터를 사용하지 않는 자동 선정
- SL 수정 시 TP 유지, TP 수정 시 SL 유지
- 드래그 중 실시간 RR 갱신
- 차트 조작 후 도형 좌표 일치
- 데이터 연결 중단과 재연결
- 새로고침 후 복원
- 자동 제안값 복원

계산 예시:
- LONG: 엔트리 100, SL 98, TP 106 → RR 1:3
- SL만 97로 수정 → TP 106 유지, RR 1:2
- TP만 109로 수정 → SL 97 유지, RR 1:3
- SHORT: 엔트리 100, SL 102, TP 94 → RR 1:3

실행 가능한 전체 소스와 설치·실행 방법을 제공해줘. 미정인 전략 기준은 초기 가정으로 명시하고 설정 가능하게 구현한다. 직접 실행하거나 확인하지 못한 항목은 검증 완료라고 표현하지 않는다.
