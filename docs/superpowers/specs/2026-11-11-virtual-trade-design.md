# 가상 거래 설계 (2026-11-11)

## 목적
1RC 안에서 「진입」 한 번으로 가상 거래를 시작하고, 1RC가 Bybit 공개 시세로 따라가 손절·목표에 닿으면 자동 청산해 저널에 쌓는다.
실제 체결 가져오기(CSV·API)는 나중의 고급 기능 — 이번 범위 밖.

사용자가 정한 것: 키보드가 아니라 버튼(마우스·터치), 폰에서도 동작, 진입 단계는 단순하게(차트 박스 옆 버튼 한 번, 묻는 것 없음).

## 진입
- 계산(LONG/SHORT 박스)이 있고 손절가가 있으면 차트의 박스 옆에 「진입」 버튼이 보인다. 손절가가 없으면 버튼은 꺼져 있고 이유를 title로 알린다.
- 누르면 바로 저널 「진행 중」에 올라간다. 진입가 = 계획한 진입가, 시각 = 누른 순간. 셋업·품질·근거·규칙 체크는 묻지 않는다(기본값). 나중에 저널에서.
- 같은 계산은 한 번만. 진입한 계산이면 버튼이 「✓ 진행 중」(저널로 가는 링크)으로 바뀐다.
- 직후 5초 「되돌리기」(기존 되돌리기 막대).
- 하루 거래 수·손실 한도 경고는 기존대로 패널 위에 뜬다. 막지는 않는다.
- 기존 「📒 저널에 기록」 폼은 없앤다.

## 자동 추적
- 대상: 저널의 열린 거래 전부.
- 자료: Bybit 공개 1분 캔들 (`/v5/market/kline`, API 키 없음). 마감된 캔들만 본다.
- 판정: 롱은 저가 ≤ 손절가면 손절, 고가 ≥ 목표가면 목표. 숏은 반대. 한 캔들에서 둘 다 닿으면 손절.
- 청산가 = 손절가 또는 목표가. 청산 시각 = 그 캔들이 끝난 시각. 거래에 `auto: 'sl' | 'tp'` 표시.
- 진입한 분의 캔들은 진입 전 움직임이 섞여 있어 보지 않는다(다음 분부터).
- 어디까지 봤는지 거래에 `trackedTo`로 적어 다음엔 그 뒤만 받는다. 한 번에 거래당 최대 5쪽(5,000분). 더 밀렸으면 다음 차례에 이어서.
- 언제: 계산기·저널 페이지를 열 때 + 열려 있는 동안 60초마다. 닫아 둔 동안은 다음에 열 때 따라잡는다.
- 저장 직전에 저널을 다시 읽어, 그 사이 사용자가 직접 청산한 거래는 건드리지 않는다.
- 통신 실패는 조용히 넘어가고 다음 차례에 다시 한다.

## 저널 화면
- 자동 청산되면 알림 한 줄(「BTC 롱 손절 닿음 −1.00R」).
- 거래 목록 「규칙 · 상태」 칸에 「자동 · 손절」/「자동 · 목표」 꼬리표. 칩은 「채우기」로 나중에.
- 청산 카드에 「지금 가격으로」 버튼: Bybit 공개 시세의 현재가를 청산가 칸에 채운다(저장은 직접).

## 데이터
`Trade`에 선택 항목 추가: `auto?: 'sl' | 'tp'`, `trackedTo?: number`. `version: 1` 그대로, 예전 기록·백업 호환.

## 한계 (화면 도움말에 한 줄)
가상 체결이라 실제 체결가·미끄러짐·펀딩비와 다를 수 있다. 수수료는 기존 수수료율로 뺀다.

## 테스트
- 단위: 판정(롱/숏, 둘 다 닿음, 목표 없음, 진입 분 제외), 쪽 나눠 받기, 추적 실행(가짜 통신), 저장 직전 다시 읽기.
- e2e: 진입 버튼 → 저널에 열린 거래 → 되돌리기; 저널에서 가짜 캔들로 자동 청산.
