# 저널 개편 설계 (2026-11-11)

## 목적
- 저널을 열면 **지금 할 일(청산 기록)** 이 맨 위에 보이고, 기록은 탭 2번으로 끝난다.
- 달력으로 한 달 흐름을 본다. 주말에 한 주를 돌아보고 다음 주 고칠 것 하나를 정한다.
- 사용자는 한 명(본인). 데이터는 지금처럼 브라우저(localStorage)에만 둔다. 서버 전송 없음.

사용자가 정한 것: B안(할 일이 첫 화면) + 달력 형태도 볼 수 있게.
아래 "가정" 표시는 사용자가 직접 말하지 않아 내가 정한 것이다.

## 첫 화면 순서 (위 → 아래)
1. **이번 주 한 줄** — 지난 주 리뷰에서 적은 「다음 주 고칠 것」. 리뷰를 아직 안 썼고 지난 주에 거래가 있었으면 이 자리에 「이번 주 돌아보기」 카드가 대신 뜬다. (가정: 일요일만이 아니라 안 쓴 동안 계속 뜸)
2. **열린 거래 = 청산 카드** — 열린 거래마다 카드 하나. 없으면 이 칸은 안 보인다.
3. **숫자 3개** — 점수 · 연속 기록 · 이번 주 R.
4. **달력** — 기본은 최근 4주 띠. 「달력 전체 보기」를 누르면 그 자리에서 한 달 달력으로 펼쳐진다. 마지막에 본 형태를 기억한다. 날짜를 누르면 아래 거래 목록이 그날 것만 보인다.
5. **누적 R 곡선 + 가장 약한 곳 한 줄.**
6. **탭** — 거래 목록 / 통계 / 설정. 기존 화면(요약, 손실 한도, 그룹 통계, 설정, 백업)은 여기로 옮긴다. 기능은 지우지 않는다.

진입 기록(계산기에서 저널로 넘기는 흐름)은 그대로 둔다.

## 청산 카드
- 청산가 입력 → 결과 R이 바로 보인다.
- 칩 두 줄, 각각 하나만 고른다.
  - 규칙 지켰나: 지켰다 / 손절 옮김 / 일찍 청산 / 계획 없이 진입
  - 그때 상태: 차분 / 조급 / 복수심 / 피곤
- 「저장」. 칩을 안 골라도 저장된다(나중에 거래 목록에서 채울 수 있음). 글자 입력 없음.
- 「손절가로」「목표가로」 버튼은 청산가 칸만 채운다(지금은 바로 청산됨 → 칩을 고를 틈을 주려고 바꿈).

## 주간 리뷰 카드
- 자동 요약: 지난 주 거래 수, 승률, 합계 R, 규칙 준수 n/m.
- 입력 두 줄: 「반복된 패턴 한 줄」, 「다음 주 고칠 것 하나」 (각 200자 이하).
- 한 주는 월요일 00:00 ~ 일요일, 하루는 00:00 ~ 24:00. 모두 한국 시간 기준 (기존 `periodStart`와 같음). 달력의 날짜도 청산 시각의 한국 날짜로 나눈다.

## 숫자 정의
- **점수 (0~100)**: 최근 30일의 청산 거래로 계산. 10개 미만이면 숫자 대신 「거래 10개부터」.
  각 25점: ① 수익 — 거래당 평균 R이 −0.5R 이하면 0점, +0.5R 이상이면 만점, 사이는 비례 ② 규칙 준수 — 규칙 지킨 비율 ③ 손실 관리 — 손실 거래 중 −1.1R보다 크게 잃지 않은 비율(손실 거래가 없으면 만점) ④ 꾸준함 — 칩 두 줄을 다 채운 거래 비율.
- **연속 기록**: 청산한 거래가 있는 날 중, 그날 거래 전부에 칩 두 줄이 채워진 날이 연달아 며칠인지. 거래 없는 날은 끊기지 않는다.
- **규칙 위반**: 진입 때 「규칙 위반」으로 표시했거나, 청산 칩이 「지켰다」가 아닌 거래. 칩을 안 고른 거래는 진입 때 표시만 따른다.
- **가장 약한 곳**: 세션 × 방향, 셋업별 묶음 중 합계 R이 가장 낮은 것. 묶음에 거래 5개 이상이고 합계가 마이너스일 때만. 없으면 줄을 숨긴다.
- **통계 탭 추가**: 최대 낙폭(R), 최대 연속 승/패, 평균 보유 시간, 월별 표(거래 수 · 승률 · 합계 R).

## 데이터
기존 저장 형식(`version: 1`)에 선택 항목만 더한다. 예전 데이터와 예전 백업 파일은 그대로 읽힌다.
- `Trade.closeRule?`: `'kept' | 'movedSl' | 'earlyExit' | 'noPlan'`
- `Trade.mood?`: `'calm' | 'rushed' | 'revenge' | 'tired'`
- `Journal.reviews?`: `{ weekStart: number; pattern: string; fix: string; writtenAt: number }[]` (주마다 하나, 같은 주는 덮어씀)
- 달력 보기 형태: `rrtool.v1.journalCalView` = `'strip' | 'month'`

읽을 때 검사: 칩 값은 위 목록에 있는 것만, 글은 문자열·200자 이하만 받는다. 아니면 그 항목만 버린다. 백업 저장/불러오기와 합치기(`mergeJournal`)에 리뷰를 포함한다(같은 주는 나중에 쓴 것 유지). CSV에 두 칸(규칙, 상태)을 더한다.

## 코드 구조
- `src/core/journalInsights.ts` (새 파일, 화면 없는 순수 계산): 날짜별 합계, 점수, 연속 기록, 가장 약한 곳, 최대 낙폭·연속 승패·보유 시간, 월별 표, 주간 요약.
- `src/core/journal.ts`: 타입·읽기 검사·백업·CSV만 고친다.
- `src/journal/main.ts`(407줄)는 탭과 전체 그리기만 남기고 나눈다: `home.ts`(첫 화면), `closeCard.ts`, `calendar.ts`, `review.ts`. 기존 그리기 함수는 탭 쪽으로 옮긴다.
- 화면에 넣는 사용자 글(리뷰, 셋업 이름)은 `textContent`로만 넣는다. 외부 통신·새 라이브러리 없음. 곡선은 SVG로 직접 그린다.

## 오류 처리
- 청산가가 숫자가 아니거나 0 이하면 저장 버튼을 막고 칸 아래에 이유를 적는다.
- localStorage 저장 실패 시 기존 `alertBox` 경고를 쓴다.
- 거래가 하나도 없으면 첫 화면에 「계산기에서 첫 거래를 저널로 보내 보세요」 한 줄만 보인다.

## 테스트
- 단위(vitest): `journalInsights` 전 함수(빈 데이터, 10개 미만, 경계값), 새 항목 읽기 검사, 예전 백업 읽기, 리뷰 합치기.
- e2e(Playwright): 청산 카드로 칩 2번 + 저장 → 달력 그날 칸에 R 표시, 달력 펼침 상태 기억, 주간 리뷰 저장 → 다음에 열면 한 줄로 표시. 화면 폭 390px에서 가로 스크롤 없음.
