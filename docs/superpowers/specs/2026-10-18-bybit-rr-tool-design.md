# Bybit 선물 RR 툴 — 설계 문서

- 작성일: 2026-10-18
- 원본 요구사항: `2026-10-18-original-request.md` (사용자 작성, 이 문서의 상위 권한)
- 진행 방식: 사용자가 질문을 생략하고 "바로 시작"을 선택. 아래 "결정 사항"은 모두 빌더(Claude)의 판단이며 사용자가 승인한 내용이 아니다.

## 1. 의도

사용자가 원하는 순간 LONG/SHORT를 누르면 그 순간의 최신 체결가를 엔트리로 고정하고, 가격 구조(현재 시간봉의 급격한 캔들 꼬리, 상위 시간봉의 확정 스윙)로 SL·TP를 제안한다. RR은 결과로 계산될 뿐 목표가 아니다. 유저는 SL·TP를 드래그나 입력으로 고치고, RR·손익률은 즉시 갱신된다. 실제 주문이 아닌 가상 시나리오다.

## 2. 목표 / 비목표 / 반목표

- 목표: 원본 요구사항 1~9절 전체를 MVP로 구현. 사용자가 확정한 시장은 **Bybit USDT 무기한 선물(category=linear)**.
- 비목표(v1 제외): 엔트리 수정, 다중 시나리오, 수량·금액 손익, 수수료·슬리피지·레버리지 반영, 실제 주문.
- 반목표(동작해도 실패로 보는 것):
  - 엔트리 이후 데이터가 SL/TP 자동 선정에 섞이는 것
  - 목표 RR에 맞춰 TP를 역산하거나, 무효한 자동값을 설명 없이 다른 값으로 바꾸는 것
  - SL을 고쳤는데 TP가 움직이는 것(반대도 동일)
  - 오래된 가격으로 시나리오가 생성되는 것
  - 데모 데이터가 실데이터처럼 보이는 것

## 3. 데이터 공급원 사실 (Bybit V5 공식 문서, 2026-10-18 확인)

- REST 캔들: `GET /v5/market/kline` — interval `1,3,5,15,30,60,120,240,360,720,D,W,M`, limit 1~1000(기본 200), 응답 `result.list`는 최신순, 각 항목 `[startTime, open, high, low, close, volume, turnover]` 문자열. 미확정 캔들의 close는 마지막 체결가. 응답 최상위에 서버 시각 `time`(ms).
- REST 종목: `GET /v5/market/instruments-info?category=linear` — limit 최대 1000(기본 500), `nextPageCursor` 페이지네이션, 기본으로 `Trading`과 `PendingOpen` 반환. `priceFilter.tickSize`, `quoteCoin`, `contractType`, `status` 사용.
- WS: `wss://stream.bybit.com/v5/public/linear`, `{"op":"subscribe","args":[...]}`, ping `{"op":"ping"}` 권장 20초 간격, pong 응답 `{"op":"ping","ret_msg":"pong","success":true}`.
- WS `kline.{interval}.{symbol}`: 1~60초마다 푸시, 필드 `start,end,interval,open,close,high,low,volume,turnover,confirm,timestamp`, `confirm=true`면 확정.
- WS `publicTrade.{symbol}`: 실시간, `data`는 체결 시각 오름차순, 필드 `T`(체결 ms), `p`(가격) 등.
- WS `tickers.{symbol}`: linear 100ms, snapshot/delta, delta에서는 바뀐 필드만 옴.
- 미확인: 브라우저에서 REST 호출 시 CORS 허용 여부, 한국 IP 접속 가능 여부. (빌드 환경에서 Bybit 접속이 차단되어 확인 불가)

## 5. 구조

- `src/core/`: 순수 함수 — 시간봉, 가격/틱, RR 계산, ATR, 급격한 캔들, 스윙, 자동 선정, 시나리오 상태, 저장, 신선도
- `src/data/`: 공급원 인터페이스, 캔들 저장소, Bybit 어댑터(파싱·소켓·REST)
- `src/chart/`: 박스 기하·히트 테스트·드래그(순수), Lightweight Charts 연동(프리미티브·가격선·마커)
- `src/ui/`: 상단바, 패널, 대화상자, 앱 연결
- 차트 라이브러리: Lightweight Charts 5.2 (Apache-2.0, 시리즈 프리미티브로 커스텀 도형). 드래그는 직접 구현.
- 빌드/테스트: Vite 8, TypeScript, Vitest 5(단위), Playwright + 번들 Chromium(E2E, 테스트 전용 가짜 시세 + 가짜 Bybit 서버)
